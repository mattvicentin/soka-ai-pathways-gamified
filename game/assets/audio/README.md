# Audio Assets

This folder contains audio files for the game version.

## Required Files (Optional for POC)

The game will work without these files, but for a complete experience, add:

### Background Music

1. **contemplative.mp3** - Calm, thoughtful music for shared/balanced pathways
2. **serious.mp3** - Tense, serious music for prohibitive pathway
3. **hopeful.mp3** - Uplifting music for embracing/collaborative pathways

### Sound Effects

1. **click.mp3** - Button click sound
2. **text.mp3** - Text typewriter sound (subtle beep)
3. **transition.mp3** - Scene transition whoosh

## Free Audio Resources

You can find free, high-quality audio at:

- **FreeMusicArchive.org** (CC-BY licensed music)
- **Freesound.org** (UI sounds and effects)
- **OpenGameArt.org** (Game music and SFX)
- **Incompetech.com** (Royalty-free music by Kevin MacLeod)

## File Format

- Use **.mp3** format for best browser compatibility
- Keep files small (music < 5MB, SFX < 100KB)
- Normalize audio levels for consistent volume

## How to Add Audio

1. Download/create audio files
2. Place them in this folder with the names above
3. Refresh the game - audio will automatically load
4. No code changes needed!
